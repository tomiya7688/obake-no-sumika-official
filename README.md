# おばけの住処 — 公式案内所 👻

> 森の奥の、どこか地下。今日もかどかとまるが、ふよふよ暮らしています。

ここは「おばけの住処」シリーズの総合案内所です。作品や素材の案内だけでなく、**世界設定・キャラクター設定の本文**、ふたりの暮らし、創作メモも、このリポジトリ内で読めるようにしています。

## おばけの住処って？

森の奥を歩いていると、入口もよく分からないまま、地下へ落ちるように入り込むことがあるそうです。

薄暗い岩場には地下水が流れ、小さな水場と、どこからか拾われてきた物があります。なぜか枕とふとんもあります。

住んでいるのは**まるとかどかの2匹だけ**。昼は住処でのんびりして、夜には町や森や山へ出かけます。途中で気になった物を見つけると、1日でも数日でも寄り道します。帰ろうと思えば、住処の方向はなんとなく分かるようです。

ふたりは非力ですが、速く飛ぶことも、物をすり抜けることもできます。ただし、便利な能力を賢く使いこなすとは限りません。大事件より、毎日の小さな出来事が似合う世界です。

## 住人のご紹介

|  | まる | かどか |
| --- | --- | --- |
| どんなおばけ？ | 白く丸い、手のないおばけ | 左右に短い手のあるおばけ |
| 好きな食べ物 | りんご・梨 | みかん・柿 |
| 一人称 | 「まる」 | 「僕」 |
| 話し方 | 「〜なのだ！」をよく使う | 静かで、とても短い |
| 拾い物 | 用途の分からない変な物が多い | 比較的まともな物が多い |
| 共通点 | 人間よりずっと物知らず、非力、ふよふよしている | 人間よりずっと物知らず、非力、ふよふよしている |

かどかはまるより少し賢いだけで、人間並みの常識人ではありません。ふたりは上下関係のない同居人です。

## 公式設定資料 — ここで本文を読めます

- **[世界設定](setting/WORLD.md)** — 住処の様子、日々の生活、夜の外出と寄り道、食べ物、拾い物、すり抜けなどの設定を全文掲載。
- **[キャラクター設定](setting/CHARACTERS.md)** — まる・かどかの外見、性格、好きな食べ物、メモ、口調、ふたりの関係を全文掲載。
- **[設定整理ノート](setting/NOTES.md)** — 旧メモやゲームの独自ルールを公式世界設定と混同しないための整理。
- **[住処の小話集](stories/README.md)** — りんごやみかんをめぐる、ふたりらしい出来事。未確定の創作メモはそう明記して収録。

設定はここで実際に読めます。「詳しくは別の場所を参照」だけで終わる案内所にはしません。

## おばけ素材を使いたい方へ

かどか・まるの素材には **Obake Character License v1.2** が適用されます。条件のもとで、商用・非商用利用、改変、二次創作、ゲームや動画・グッズなどへの利用が可能です。クレジットは必須ではありませんが、公式を装うことや、公式素材そのものを主目的とする有料素材集としての再販売などは認められていません。

詳しくは **[ライセンスのご案内](LICENSE_GUIDE.md)** に要点と具体例を書いています。契約上の正本は [日本語版 LICENSE.md](https://github.com/tomiya7688/Obake_Lisense/blob/main/LICENSE.md) です（[英語参考訳](https://github.com/tomiya7688/Obake_Lisense/blob/main/LICENSE.en.md)）。

## 設定と創作メモの扱い

この案内所の世界・キャラクター本文は、[chatgpt-obakenosumika](https://github.com/tomiya7688/chatgpt-obakenosumika) の WORLD.md / CHARACTERS.md から取り込んだ掲載版です。また、非公開の個人用メモリに保管されていた**作品「おばけの住処」に関する創作メモだけ**を選び、小話として掲載しています。個人的な情報や無関係なメモは転載しません。

- **確定済みの世界・キャラクター設定**：setting/ の本文。
- **小話・描写案**：stories/ の「創作メモ」。読み物ですが、書かれたすべてが確定設定という意味ではありません。
- **ゲームの実装ルール**：それぞれのゲーム固有の仕様。おばけ全般の法則と混同しません。

元の設定管理元は引き続き [chatgpt-obakenosumika](https://github.com/tomiya7688/chatgpt-obakenosumika) の main ブランチで、食い違う場合はそちらが優先です。ただしこのリポジトリにも**本文を収録**しているため、住処の世界を読むために別ページへ移動する必要はありません。転載・整理の情報は [資料の出典と更新について](SOURCES.md) をご覧ください。
